Calculates an energy term based on component overlap.

Parameters
*modelmodel structure.
*mdmodel dynamics structure.
Returns
double total overlap energy. 
The energy is defined as linear decay to the reference separation distance
and zero beyond:
    Esep = Ksep * (1 - d/dsep)  for  d < dsep, zero otherwise

Randomly transforms models.

Parameters
*modelmodel structure.
max_anglemaximum rotation angle.
shift_stdgaussian length for shift vector.
rigidwhich part for rigid transformation: 0=all, 1=each model.
Returns
int 0. 
The transformation is calculated as a random angular rotation and a
random shift. The shift is sampled from a random vector with a
gaussian length distribution.

Only one model is rotated if rigid is one.
